# 👑 KQLF – King & Queen Luxury Fashion

> **RULE YOUR STYLE. TRY IT. SEE IT. RULE IT.**

KQLF (King & Queen Luxury Fashion) is an AI-powered fashion e-commerce platform designed to provide customers with a modern online shopping experience and an AI-powered virtual try-on experience.

The project combines a React.js storefront with a Python/FastAPI backend and an AI virtual try-on service based on IDM-VTON.

---

## ✨ Features

### 🛍️ E-Commerce

- Browse fashion products
- Product details
- Product categories
- Wishlist functionality
- Shopping cart
- Checkout flow
- Responsive fashion-focused UI
- KQLF branded product experience
